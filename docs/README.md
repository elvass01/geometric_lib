# geometric_lib

Простая библиотека на Python. Считает площадь и периметр круга, квадрата, прямоугольника и треугольника.
Для каждой фигуры свой файл, и в каждом есть функции `area` и `perimeter`.

## Функции

### Круг (circle.py)

#### `area(r)`

Возвращает площадь круга по его радиусу.

- **Параметры:** `r` (int | float) — радиус круга
- **Возвращаемое значение:** (float) — площадь круга, вычисленная по формуле S = π·R²

#### `perimeter(r)`

Возвращает длину окружности (периметр круга) по его радиусу.

- **Параметры:** `r` (int | float) — радиус круга
- **Возвращаемое значение:** (float) — длина окружности, вычисленная по формуле P = 2·π·R

```python
import circle

print(circle.area(1))       # 3.141592653589793
print(circle.perimeter(1))  # 6.283185307179586
```

### Квадрат (square.py)

#### `area(a)`

Возвращает площадь квадрата по длине его стороны.

- **Параметры:** `a` (int | float) — длина стороны квадрата
- **Возвращаемое значение:** (int | float) — площадь квадрата, вычисленная по формуле S = a²

#### `perimeter(a)`

Возвращает периметр квадрата по длине его стороны.

- **Параметры:** `a` (int | float) — длина стороны квадрата
- **Возвращаемое значение:** (int | float) — периметр квадрата, вычисленный по формуле P = 4·a

```python
import square

print(square.area(5))       # 25
print(square.perimeter(5))  # 20
```

### Прямоугольник (rectangle.py)

#### `area(a, b)`

Возвращает площадь прямоугольника по длинам двух его сторон.

- **Параметры:**
  - `a` (int | float) — длина первой стороны прямоугольника
  - `b` (int | float) — длина второй стороны прямоугольника
- **Возвращаемое значение:** (int | float) — площадь прямоугольника, вычисленная по формуле S = a·b

#### `perimeter(a, b)`

Возвращает периметр прямоугольника по длинам двух его сторон.

- **Параметры:**
  - `a` (int | float) — длина первой стороны прямоугольника
  - `b` (int | float) — длина второй стороны прямоугольника
- **Возвращаемое значение:** (int | float) — периметр прямоугольника, вычисленный по формуле P = 2·(a + b)

```python
import rectangle

print(rectangle.area(3, 4))       # 12
print(rectangle.perimeter(3, 4))  # 14
```

### Треугольник (triangle.py)

#### `area(a, h)`

Возвращает площадь треугольника по основанию и высоте.

- **Параметры:**
  - `a` (int | float) — длина основания треугольника
  - `h` (int | float) — высота, опущенная на основание
- **Возвращаемое значение:** (float) — площадь треугольника, вычисленная по формуле S = a·h / 2

#### `perimeter(a, b, c)`

Возвращает периметр треугольника по длинам трёх его сторон.

- **Параметры:**
  - `a` (int | float) — длина первой стороны
  - `b` (int | float) — длина второй стороны
  - `c` (int | float) — длина третьей стороны
- **Возвращаемое значение:** (int | float) — периметр треугольника, вычисленный по формуле P = a + b + c

```python
import triangle

print(triangle.area(3, 4))          # 6.0
print(triangle.perimeter(3, 4, 5))  # 12
```
